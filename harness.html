What a harness is

Look it up.
Don’t recall it.

A harness is the environment around an agent: the tools it can reach, the state it can see, and the checks on its output. Following HARBOR, we apply it to the repository itself.

01

One registry

Eleven YAML files hold the robot’s facts: hosts, ports, control paths, safety limits, firmware, APIs.

02

One namespace

Every command is /mabel-<verb>.

03

One gate

/mabel-drift checks that every cited file still exists and still contains its fact. Drift fails like a test.

The registry

Every answer
cites a file.

Commands render the registry in claude_harness/data/. Each entry records its source path. An entry without one is rejected.

FileHolds
commands.yamlThe command surface; this page is generated from it
hosts.yamlThe robot computer, the relay, the dev host: addresses, roles, access
network.yaml43 ports, their protocols, and the relay route
control.yaml14 control methods, 11 launch targets, 9 studios
safety.yamlE-stop, watchdogs, motion limits, arbitration, each with its implementation
firmware.yamlMCU, bus, protocol and build/flash commands per subsystem
controller_api.yamlThe mabel control library’s public API
hardware_api.yamlThe mabel_hw HAL: drivers, RPC, cameras, config
subsystems.yamlEach top-level directory and the data flow between them
docs.yaml · glossary.yaml45 technical papers; project vocabulary
Gates

Checks that fail.

Documentation goes stale silently. Each gate turns one kind of staleness into a failure, and states what it does not cover.

GateWhat it catches
citationA fact whose source file was deleted, moved, or no longer contains it.
surface →A listed command with no definition in the repo.
surface ←A command in the repo that the registry does not list.
viewA command pointing at a renamed engine view.
papersA subsystem whose docs/*.tex is missing.
safety sourcesA safety mechanism citing a file that no longer implements it.
Limit. drift checks citations, not architecture. It passed during the neck migration while the invariant it documents was violated. Invariants are enforced by tests in hardware_bridge/tests/.

What it won’t do.

Design choices, recorded in the registry and printed by /mabel-help.

    Use it

    Clone it.
    Ask it.

    The harness ships with the repository. Any assistant that reads .claude/commands/ loads the 25 commands. Plain questions, such as “what’s on port 9090?”, reach the same registry.

    First

    /mabel-onboard

    The robot, the subsystem map, the hosts, the wire contract, the two fixed rules.

    Then

    /mabel-safety

    Read before driving. Every base command passes one safety function.

    Any time

    /mabel-help

    The full surface, including what it will not do.
