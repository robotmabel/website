What a harness is

Look it up.
Don’t recall it.




A harness is the environment around an agent: the tools it can reach,
        the state it can see, and the checks on its output. Following
        HARBOR,
        we apply it to the repository itself.






01
One registry


Eleven YAML files hold the robot’s facts: hosts, ports, control paths,
          safety limits, firmware, APIs.


02
One namespace


Every command is /mabel-<verb>.


03
One gate


/mabel-drift checks that every cited file still exists and still
          contains its fact. Drift fails like a test.
















The registry

Every answer
cites a file.




Commands render the registry in claude_harness/data/.
        Each entry records its source path. An entry without one is rejected.








FileHolds



commands.yamlThe command surface; this page is generated from it


hosts.yamlThe robot computer, the relay, the dev host: addresses, roles, access


network.yaml43 ports, their protocols, and the relay route


control.yaml14 control methods, 11 launch targets, 9 studios


safety.yamlE-stop, watchdogs, motion limits, arbitration, each with its implementation


firmware.yamlMCU, bus, protocol and build/flash commands per subsystem


controller_api.yamlThe mabel control library’s public API


hardware_api.yamlThe mabel_hw HAL: drivers, RPC, cameras, config


subsystems.yamlEach top-level directory and the data flow between them


docs.yaml · glossary.yaml45 technical papers; project vocabulary



















Gates

Checks that fail.




Documentation goes stale silently. Each gate turns one kind of staleness
        into a failure, and states what it does not cover.








GateWhat it catches



citationA fact whose source file was deleted, moved, or no longer contains it.


surface →A listed command with no definition in the repo.


surface ←A command in the repo that the registry does not list.


viewA command pointing at a renamed engine view.


papersA subsystem whose docs/*.tex is missing.


safety sourcesA safety mechanism citing a file that no longer implements it.








Limit. drift checks citations, not architecture. It passed during the
      neck migration while the invariant it documents was violated. Invariants are enforced by
      tests in hardware_bridge/tests/.

Use it

    Install the guides.
    Explore the source.
    

    

    Download the public command pack and extract it into your open_mabel checkout. Open Claude Code there and run /onboarding. The pack contains 25 read-only source tours plus onboarding aliases.
    

    

    

    First
    /mabel-onboard
    

    The robot, public subsystem map, model ownership and next commands.
    

    Then
    /mabel-safety
    

    Inspect the controller’s motion gate and the files that implement it.
    

    Any time
    /mabel-help
    

    Locate public documentation and identify full-harness components absent from this checkout.
    

    

    cd open_mabel
unzip /path/to/public-command-pack.zip
claude
# Then type /onboarding
