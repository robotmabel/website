Software

One graph. Every joint.
Sim or real.

One ROS 2 graph wraps every bus behind standard topics. A MuJoCo twin runs the same control code as the robot. A teleop server puts both behind one contract, so a Vision Pro, an iPhone or a browser drives sim or hardware without knowing which. Flip one flag to choose the world.

The stack

Six pieces, one interface.

Each piece is its own page — the graph that carries every joint, the twin you prove motion in first, the contract that lets a headset skip ROS entirely, and the control library every command must pass through. Start anywhere.

01 · Graph

ROS 2

One graph wraps every bus behind standard topics. The live topic map, both boot modes, the command contract, and what's inside mabel_ws/src.
02 · Twin

Simulation

A MuJoCo twin running the same control code as the robot, at 500 Hz. Prove the motion here, then flip one flag.
03 · System ID

Calibration

Two bench fits recover the friction, rotor inertia, mass and centre of mass CAD never gives you — then write them back into the model.
04 · Contract

Server & Bridge

Eight JSON messages in, MJPEG out. A Vision Pro, an iPhone or a browser drives sim or hardware without ever importing ROS.
05 · Gate

Controller

Three nested loops turn a 6-DOF wish into safe motion at 51 joints. Every command from every device passes through here.
06 · Whole body

Whole-Body Control

Redundancy resolved across base, lift, torso and arms — strong where it must be, soft where you touch it.

Stack is up. Now drive it.
