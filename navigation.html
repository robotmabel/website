Mapping & SLAM

Built from the base up.

The robot maps and localizes with sensors that ride on the mobile base — no external motion capture, no tether.

SLAM map · occupancy grid + RGB-D cloud
mabel_slam

Two maps, one world.

The base 2-D LiDAR feeds SLAM Toolbox, turning raw scans into a clean occupancy grid with loop closure for fast, reliable planning. The onboard RGB-D cameras add a dense visual layer — so MABEL maps and localizes by what it senses, not just what it bumps into.

Path planning

Nav2, tuned holonomic.

mabel_navigation runs the Nav2 stack against the SLAM map, configured for the omnidirectional swerve base.

01
Localization

Scan-matching against the LiDAR grid, corrected by visual loop closures from the base cameras — MABEL holds its pose down long, repetitive corridors.

02
Nav2 stack

A global planner finds the route; a local controller tracks it while dodging obstacles. Costmaps fuse LiDAR and depth; recovery behaviors handle the dead ends.

03
Holonomic by default

Nav2 is configured for an omnidirectional footprint, so the swerve base strafes and rotates as one — through doorways, around islands, into elevators.

04
Building-scale

Pre-built floorplans with live SLAM correction carry MABEL across rooms and floors — long-horizon mobility for whole-body manipulation tasks.

Onboard sensing

Everything it needs to navigate, it carries.

01

Base 2-D LiDAR

A planar scanner on the mobile base feeds the occupancy grid and the Nav2 costmap.

02

RGB-D cameras

Onboard depth cameras add a dense visual layer for loop closure and obstacle avoidance.

03

Wheel odometry

Swerve drive and steer encoders provide the dead-reckoning prior SLAM corrects against.

04

Occupancy grid

SLAM Toolbox fuses scans into a 2-D grid with loop closure for fast, reliable planning.

05

Costmaps

Global and local costmaps fuse LiDAR and depth so the controller plans around real obstacles.

06

Recovery

Behavior-tree recoveries clear costmaps and re-plan when the robot wedges into a dead end.
