Overview / Software / ROS
L2 · ROS 2

One graph, every joint.

A single ROS 2 Humble workspace — mabel_ws — wraps every firmware target behind standard topics: drivers, sensors, descriptions, and custom interfaces. One launch file brings up the whole robot over DDS.

ROS 2 HumbleUbuntu 22.04DDScolcon/joint_states
The workspace

Wrapped behind clean topics.

Every firmware bus surfaces in ROS the same way — joint command in, joint state out. Consumers never see CAN, RS-485, or Dynamixel; they see topics.

01
Hardware drivers

mabel_base_hardware, mabel_arms_hardware, mabel_body_hardware, and mabel_orca_hand bridge each firmware bus to ROS — publishing /joint_states, subscribing to commands at 200 Hz+.

02
Sensors & time base

mabel_sensors brings up the head RGB-D, two eye-in-hand wrist cameras, and the base 2-D LiDAR — hardware-timestamped onto one clock so images, scans, and joint states line up to the millisecond.

03
Description & interfaces

mabel_description holds the URDF, meshes, and RViz config — the same kinematic tree used in sim. mabel_interfaces defines the custom messages and services the stack speaks.

04
Teleop bridge

mabel_teleop routes Apple Vision Pro and keyboard input into the same command topics the drivers listen on — the teleop path and the autonomy path are interchangeable. See Teleop.

Bring-up

One command, whole robot.

Build once with colcon, then launch the full stack — base, arms, hands, sensors, and description — from a single entry point.

01
Build the workspace

rosdep install pulls dependencies, then colcon build --symlink-install builds every package; source install/setup.bash and the stack is live.

02
Launch the stack

ros2 launch mabel_bringup robot.launch.py starts base, arms, hands, sensors, and description together over DDS — no per-subsystem babysitting.

03
Sim parity

The same topic names and message types drive the MuJoCo / Isaac twin, so behavior validated in sim deploys with no glue code. See Simulation.

04
Layers above

Navigation and whole-body control subscribe to the same graph — Nav2 + SLAM below, application software above.
