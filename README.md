# MABEL — project website

The public site for **MABEL**, the open-source mobile bimanual robot. Static HTML/CSS/JS,
served with GitHub Pages straight from `main`.

The robot itself — hardware, firmware, control, simulation, teleop, learning — lives in
[robotmabel/MABEL](https://github.com/robotmabel/MABEL).

## Style

The design system is [`STYLE.md`](STYLE.md): three colour voices (`--hi` warm
comic red for the highlight, `--pop` saturated cab yellow for the one thing per
screen that shouts, `--rust` for the deep voice), one button recipe that every
widget inherits, four typefaces, and the rule that every figure on the site is
generated by a script rather than drawn. Working notes and the list of things
that have bitten before are in [`CLAUDE.md`](CLAUDE.md).

Before pushing:

```bash
python3 -m http.server 8741      # from website/
./scripts/run_all.sh             # 19 checks, all must pass
python3 scripts/bump_assets.py   # cache-bust the ?v= stamps
```
