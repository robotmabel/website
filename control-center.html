Overview / Teleop / Control Center
Teleop · Control Center

The robot serves
its own cockpit.

The Control Center is a browser studio hosted by the robot itself: an rviz-class 3D visualizer (live rig, SLAM mesh, 2D map, LiDAR, camera frusta), a full teleop client (drive, manipulate with task-space IK, dexterous hands, pose-setpoint timeline), and a live server monitor (every connected client, transport, latency) — one page, no install. Anyone on the robot's network opens a URL and is simultaneously a client of the robot and an observer of its server.

Live on the robot

One page, three instruments.

Captured against the real robot: the rig posed from the 50 Hz state mirror standing inside the live nvblox reconstruction of the room, the network rail listing every connected client, and all 59 actuators graded green/yellow/red against their targets — hand motor temperatures included.

Design

Client and server, at the same time.

The studio's backend runs on the robot next to the bringup stack and serves the page; the page then talks straight to the robot's existing planes — the same contract the iPhone and Vision Pro apps use. Nothing is proxied, so remote operators drive with native latency while watching the health of the very server they are driving through.

01 · VISUALIZER

A custom rviz, in the browser

The articulated rig posed live from the robot-state mirror, inside the map it is building right now: nvblox mesh, 2D occupancy grid, Nav2 path, LiDAR, TF triads, and Foxglove-style camera frusta projecting the live MJPEG streams through the lens model — distortion-aware or rectified, with point-size and projection-distance controls.

02 · CONTROL

Drive, manipulate, dexterity

Start Teleop, then switch 1st ↔ 3rd person and Drive ↔ Manipulate. On-screen joysticks or WASD keys drive the base; in manipulate mode a draggable target ball runs damped-least-squares IK on the arm. Stiff ↔ Soft gates everything: Soft makes the page a pure viewer while the robot is moved by hand. The dexterity window controls both ORCA hands — per-joint, per-finger, or grasp slider with the nine firmware poses.

03 · MONITOR

Watch the server you drive

The network rail shows the robot host's interfaces, service planes, CPU and thermals, plus every connected client — device type, transport (LAN / Tailscale / Relay), geography, command rate, and who currently holds the driver seat. A 59-DOF telemetry band grades each actuator's tracking error and temperature in real time.

Run it

One command on the robot.

The Control Center lives in the MABEL monorepo under control_center/ and starts with one script on the robot host. Without ROS it boots against a synthetic 59-DOF plant, so the whole studio also works as an offline demo.

# on the robot (thor) — auto-detects ROS, falls back to a mock plant
./control_center/run.sh                 # → http://<robot>:8094

# then from any browser on the network
open http://10.20.54.117:8094           # LAN
open http://100.87.253.64:8094          # Tailscale
